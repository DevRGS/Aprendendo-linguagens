# Bancada de HTML e CSS

Basta um editor de texto e um navegador com ferramentas de desenvolvedor. Extraia o material antes de abrir os arquivos. Use UTF-8 e mantenha a extensão .html. No Windows, confirme no Explorador que o arquivo não recebeu .txt no fim. Cada pasta numerada em aulas/ contém uma página inicial independente. Quando uma aula pedir para editar o corpo, altere somente o trecho entre as marcas body no index.html. As folhas de estilo são estilo.css ao lado do documento. As alterações feitas apenas no inspetor do navegador desaparecem ao recarregar.

| Experimento | Como conferir |
|---|---|
| Nome de um controle | Inspecione a árvore de acessibilidade no navegador. |
| Regra vencedora | Abra Estilos e Computado nas ferramentas de desenvolvedor. |
| Ordem da navegação | Pressione Tab, Shift+Tab e Enter. No macOS, habilite a navegação de teclado para todos os controles conforme seu navegador. |
| Largura pequena | Na simulação de aparelho, teste 390 px e aumente o zoom ou o tamanho do texto. |
| Caminho relativo | Abra a página também sob uma pasta de projeto, respeitando letras maiúsculas e minúsculas. |
