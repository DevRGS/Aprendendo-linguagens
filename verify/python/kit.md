Escolha a aula e siga os passos na ordem. Cada pasta corresponde a uma atividade.

1. Abra um terminal na raiz extraída. Cada comando da aula parte dessa raiz.
2. Em `e1`, leia o enunciado e execute o exemplo. Em `e2`, faça a variação.
3. Abra `e3/exercicio.py` num editor de texto, complete a atividade e salve em UTF-8.
4. Depois de testar o seu código, compare com `e3-resolvido/solucao.py` e o README da solução.
5. Volte à central para concluir a aula e revisar com o quiz e os flashcards.

Nos comandos, use o Python 3.14. Confira a versão com `py --version` no Windows ou
`python3 --version` em Linux e macOS. Se apenas `python --version` mostrar o
Python 3.14 no Windows, use `python` no lugar de `py`. Se `python3` apontar
para outra versão, use `python3.14`. O [instalador oficial do Python](https://www.python.org/downloads/)
tem opções por sistema. Reabra o terminal depois de instalar.
