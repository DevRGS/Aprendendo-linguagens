# Trilha Python · Kit completo

Abra as pastas numeradas em ordem. Cada módulo tem um README com a preparação e
a verificação de suas quatro aulas. Execute os comandos a partir da raiz desse
módulo. O projeto final e seus dados sintéticos estão em `16-projeto`.

O arquivo `requirements.txt` registra as dependências da trilha de dados. Uma
cópia está em cada módulo que usa uma dessas bibliotecas.
