# Bancada de HTML e CSS

Cada pasta em aulas/ corresponde a uma aula na ordem da trilha. Abra o
index.html da pasta no navegador e edite a mesma cópia em seu editor. Após
salvar, recarregue a página. Os arquivos têm codificação UTF-8.

Em projeto/README.md, comece pelo enunciado e pela pasta inicial. Use a
solução para conferir sua entrega e experimente a variação com uma nova trilha.
